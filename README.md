# 🏰 Castle Hardcore

**Castle Hardcore** is a challenging 2D castle-based game developed for a Hack Club event. Built using the Godot Engine, it offers intense difficulty and engaging gameplay for players seeking a hardcore experience.

---

## 🎮 About the Game

Embark on a perilous journey through a treacherous castle filled with formidable enemies and obstacles. Precision, strategy, and quick reflexes are essential to survive and conquer the challenges that await.

---

## 🚀 Features

- **High Difficulty** – Designed for players who enjoy a tough challenge.
- **2D Platformer Mechanics** – Classic side-scrolling action with modern twists.
- **Godot Engine** – Leveraging the capabilities of Godot for smooth gameplay.
- **Custom Scripts** – Tailored GDScript code for unique game behaviors.

---

## 🛠️ Built With

- [Godot Engine](https://godotengine.org/)
- GDScript
